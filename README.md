# מדד ה-S-Book

מחשבון וספרייה ציבוריים לדירוג רמת המיניות בספרים, מותאמים לפרופיל הקורא.

**האתר:** https://roee-design.github.io/s-book/

## איך זה בנוי

| חלק | שירות | עלות |
|---|---|---|
| אחסון האתר | GitHub Pages | חינם |
| מסד נתונים | Supabase (פרויקט `zhocbkdadiuhdyjdqjfn`) | חינם |
| השארת המסד ער | GitHub Action יומי (`.github/workflows/keep-alive.yml`) | חינם |

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האתר כולו |
| `supabase-config.js` | כתובת הפרויקט ומפתח ה-anon. המפתח ציבורי מטבעו |
| `supabase/migrations/001_init.sql` | טבלאות, הרשאות ופונקציות הכתיבה |
| `supabase/seed.sql` | 11 דירוגי הפתיחה |
| `ADMIN-KEY.txt` | קוד המנהל. **נמצא רק במחשב המקומי ולא מועלה ל-GitHub** |

## זהות והרשאות

- **בלי חשבונות:** אין סיסמאות ואין אימייל. כל דפדפן מקבל קוד אישי אקראי שנשמר אצלו, ובמסד נשמר רק הגיבוב (SHA-256) של הקוד.
- **מעבר בין מכשירים:** ב"שינוי פרופיל" אפשר להעתיק את הקוד למכשיר אחר, או להדביק קוד ממכשיר אחר.
- **קריאה:** כל אחד יכול לקרוא דירוגים, שמות תצוגה והסכמות.
- **כתיבה:** כל הכתיבות עוברות דרך פונקציות במסד (`save_rating`, `delete_rating`, `set_like`, `save_profile`), וכל אחת מהן בודקת את הקוד האישי.
  - כל משתמש יכול לשנות רק את הדירוגים שלו.
  - אי אפשר להסכים עם דירוג של עצמך.
  - מנהל יכול לערוך ולמחוק כל דירוג.
- **כניסת מנהל:** נכנסים ל-`…/s-book/#admin` ומדביקים את הקוד מ-`ADMIN-KEY.txt`.
