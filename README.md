# מדד ה-S-Book

מחשבון וספרייה לדירוג רמת המיניות בספרים, מותאמים לפרופיל הקורא.

- **אחסון:** GitHub Pages (חינם)
- **מסד נתונים והתחברות:** Firebase, תוכנית Spark (חינם, בלי כרטיס אשראי)

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האתר כולו |
| `firebase-config.js` | פרטי החיבור ל-Firebase. כל עוד הערך הוא `null`, האתר עובד כמחשבון בלבד |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |

## הקמת Firebase (פעם אחת, בערך 10 דקות)

1. **יצירת פרויקט:** נכנסים ל-https://console.firebase.google.com, לוחצים **Create a project** ונותנים שם (למשל `s-book`). את Google Analytics אפשר לכבות.
2. **מסד נתונים:** בתפריט **Build → Firestore Database**, לוחצים **Create database**, בוחרים מיקום (למשל `eur3`) ומתחילים ב-**production mode**.
3. **כללי אבטחה:** בלשונית **Rules** מוחקים את מה שיש, מדביקים את כל התוכן של `firestore.rules` ולוחצים **Publish**.
4. **התחברות:**
   - בתפריט **Build → Authentication → Get started → Sign-in method** מפעילים את **Google**.
   - בלשונית **Settings → Authorized domains** מוסיפים את הדומיין של GitHub Pages (למשל `USERNAME.github.io`).
5. **פרטי החיבור:** ב-**Project settings** (גלגל השיניים) → **Your apps**, לוחצים על סמל ה-Web (`</>`) ורושמים אפליקציה. מעתיקים את האובייקט `firebaseConfig` לקובץ `firebase-config.js`, במקום `null`.
6. **הגדרת מנהל:**
   - מתחברים לאתר עם Google ונכנסים ל"שינוי פרופיל". שם מופיע **מזהה המשתמש**.
   - ב-Firestore לוחצים **Start collection**, קוראים לה `admins`, ומשתמשים במזהה כ-Document ID. אפשר להוסיף שדה כלשהו, למשל `role = "owner"`.
   - מרעננים את האתר. תופיע תגית "מנהל", ובספרייה יופיע כפתור לטעינת 11 דירוגי הפתיחה.

## מה כל אחד יכול לעשות

| מי | הרשאות |
|---|---|
| כל מבקר | מחשבון, הרשמה (הפרופיל נשמר בדפדפן), עיון בספרייה ובעמודי הספרים |
| משתמש מחובר | גם לשמור דירוגים, לערוך ולמחוק את הדירוגים שלו, ולהסכים עם דירוגים של אחרים |
| מנהל | גם לערוך ולמחוק כל דירוג, ולטעון את דירוגי הפתיחה |

הכללים ב-`firestore.rules` אוכפים את ההרשאות האלה בשרת, ולא רק בממשק.

## מגבלות התוכנית החינמית

- 50,000 קריאות ו-20,000 כתיבות ביום.
- כל טעינה של האתר קוראת את כל הדירוגים פעם אחת. עם כמה מאות ספרים זה מספיק לכמה מאות מבקרים ביום.
- אם האתר יגדל מעבר לזה, אפשר לעבור לטעינה בעמודים.
